# line-messaging-api — LINE Messaging API 메시지 송수신 테스트 설계

QA 포트폴리오 프로젝트. 공개 플랫폼 API(LINE Messaging API)를 대상으로 **테스트 계획 수립과 테스트 케이스 설계**를 수행한 산출물이다. 요구사항은 LINE Developers 공개 문서(API reference·docs)에서 역도출했고, 테스트 실행은 범위에 포함하지 않는다. 기존 `public-api-quality-lab`(pytest 자동화 구현)과 역할을 나눠 이 프로젝트는 설계에 집중한다.

## 구성

| 파일/폴더 | 내용 |
|---|---|
| `LINE_MessagingAPI_메시지송수신_테스트계획서.md` | 테스트 계획서. 요구사항(공개 문서 역도출) 추적 매트릭스, 질의사항, 전략·설계 기법(결정 테이블·경계값·상태 전이·동등 분할·페어와이즈·오류 추정), 실행 계획, 자동화 전략 |
| `LINE_MessagingAPI_메시지송수신_테스트케이스.xlsx` | 테스트 케이스 102건 + 자동 집계. 시트: 요약 · 테스트케이스 · 테스트 데이터 · 질의사항 · API 체크리스트 · 결함 리포트 |
| `LINE_MessagingAPI_메시지송수신_설계노트.md` | 설계 결정 기록. 대상 선정, 요구사항 역도출, 질의 분리, 기법 매칭, 가이드라인 제약 아래 한도·장애 시나리오 설계, 자동화 계층, 제외한 것과 그 이유 |
| `tools/tc_data.py` | 요구사항·질의사항·TC·테스트 데이터·체크리스트·결정 테이블·상태 전이·페어와이즈의 원본 데이터 |
| `tools/build_xlsx.py` | `tc_data.py`로 케이스 xlsx 생성(수식 범위·커버리지 자체 검증 포함) |
| `tools/build_md.py` | `tc_data.py`로 계획서 md 생성(요구사항↔TC 매핑·건수 자동 반영) |

## 산출물 재생성

TC를 추가·수정할 때는 `tools/tc_data.py`를 고친 뒤 아래를 실행한다. 계획서의 매트릭스·건수와 케이스 파일이 함께 갱신된다.

```bash
cd tools && python build_xlsx.py "../LINE_MessagingAPI_메시지송수신_테스트케이스.xlsx" && python build_md.py "../LINE_MessagingAPI_메시지송수신_테스트계획서.md"
```

필요 패키지: `openpyxl`

## 설계 요약

- 요구사항 22건(REQ-01~22): Messaging API reference(공통 규약·웹훅·토큰·메시지·조회)와 docs(재시도·서명 검증·재전송·개발 가이드라인)에서 역도출, 출처 표기
- 질의사항 13건(Q01~Q13): 문서만으로 확정 불가한 동작(리트라이 키 형식·본문 불일치, 배열 경계 오류 표기, 헤더 변형, 429 세부, 재전송 간격 등) → '현재 동작 기록 후 판정'
- 테스트 케이스 102건: 12개 대분류, P1 37 / P2 46 / P3 19, 설계 근거(요구사항·리스크 기반·추가 검증) 태깅, 실행 구분(무발송 69 / 발송 27 / 장기·한도 6)
- 설계 기법: 결정 테이블(푸시 발송 결과 판정, 리트라이 키 처리), 경계값 3점(5개 메시지·5000 UTF-16 유닛·500 수신자·13 quick reply·limit 1000·24시간·14일 등), 상태 전이(리트라이 키 요청, 웹훅 전달·재전송, narrowcast phase), 동등 분할, 페어와이즈(엔드포인트 × 메시지 타입 × 알림 10조합), 오류 추정
- API 품질 체크리스트 12개 관점(계약·인증·오류 포맷·입력 검증·멱등성·비동기·페이지네이션·레이트리밋·웹훅 보안·웹훅 신뢰성·발송≠도달·호환성) → TC 연결
- 자동화 전략: API 67 / UI 22 / 수동 13. validate 엔드포인트를 1차 게이트로, 웹훅 서명은 봇서버 직접 호출로, 재시도·429 정책은 모의 서버로 검증 — 계획서 8장
- 개발 가이드라인(한도 초과·부하·무효 ID 요청 금지)을 설계 제약으로 반영: 실플랫폼 초과 관찰은 1회, 나머지는 모의 서버
- 공개 문서 조회일: 2026-10-25
